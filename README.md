# ❤️ AI Heart Stroke Risk Prediction

An AI-powered healthcare web application that predicts the likelihood of a stroke based on patient health information. The project uses Machine Learning with a Random Forest Classifier and a Flask web interface to provide real-time risk predictions.

---

## 📌 Features

- Predicts stroke risk using Machine Learning
- User-friendly Flask web application
- Professional healthcare-themed interface
- Displays stroke probability and risk level
- Handles missing values and categorical features
- Uses SMOTE to address class imbalance
- Random Forest Classifier for prediction

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/Owais-b/Heart-Stroke-Risk-Prediction.git
```

Go to the project directory

```bash
cd Heart-Stroke-Risk-Prediction
```

Install dependencies

```bash
pip install -r requirements.txt
```

Train the model

```bash
python train_model.py
```

Run the Flask application

```bash
python app.py
```

Open your browser

```
http://127.0.0.1:5000
```
